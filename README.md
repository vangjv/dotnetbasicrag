Once you have the prerequisites ready, follow the installation steps below.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vangjv/dotnetbasicrag.git
   cd dotnetbasicrag
   ```

2. Restore dependencies:
   ```bash
   dotnet restore
   ```

3. Build the project:
   ```bash
   dotnet build
   ```
